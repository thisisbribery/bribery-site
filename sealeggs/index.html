Please don't contact Intellijel for help with modified firmware. If you need support, flash the official firmware first. Flashing modified firmware is entirely at your own risk and may affect your warranty.

Keep your original Sealegs.1.3.5.0.bin. To go back to stock, flash it again with the official update procedure.

How it works

The page holds only the added code and a handful of changed constants: no part of the official firmware is included. After your file passes the version check, the patches are written into a copy in memory. The result is then checked against the expected SHA-256 for your exact mod combination.

The patches were verified in an ARM Cortex-M7 emulator running the firmware's own DSP code. Reverse, character and the stability fixes were also tested on hardware. Newer combinations (reverse without character, character or doppler on their own, character with stock Digi) have so far only been verified in emulation.

Seal Beads was developed on hardware with the full reverse + character build, and V2 has been played on hardware. It was verified in the emulator (clock handling, controls, levels, CPU load, and Tape, BBD and Digi unchanged while it is off) for every combination it can be built with.

Seal Microloops was developed on hardware with the full build plus Seal Beads. Its latest version (a fix for Shuffle stalling while TIME or WIDTH moved) has been verified in the emulator: the three modes and their variations, levels, CPU load, a stress test of fast control moves, Seal Beads unchanged, and Tape, BBD and Digi unchanged while it is off, for every combination it can be built with.
